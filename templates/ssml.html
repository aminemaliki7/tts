COMMON SSML TAGS
TAG PURPOSE
<speak> Root element
<break> Add pause
<prosody> Change speech style
<emphasis> Emphasize text
<say-as> Pronunciation type
<phoneme> Phonetic pronunciation
<sub> Substitute text
PROSODY VALUES
  • rate: x-slow, slow, medium, fast, x-fast
  • pitch: x-low, low, medium, high, x-high
  • volume: silent, x-soft, soft, medium, loud
SAY-AS CATEGORIES
  • date: dates in various formats
  • time: time expressions
  • telephone: phone numbers
  • cardinal: cardinal numbers
  • ordinal: ordinal numbers
  • characters: spell out each character
